# Native metadata preview fixture

`native-metadata-preview.json` is an exact copy of the output generated by
`tests/selected/selected_content_test.cpp` through production `ScanNative` with
`verifyHashes=false`. It was generated with production Pine AES/CTR/NCA/CNMT
code, pinned mbedTLS and independent OpenSSL encryption, using public synthetic
keys and content-free inputs. The source is the test's `MutableSource`, not an
Android FD. FD ownership has separate tests.

SHA-256: `3aefa8e5c4c16f70af5aa05c081bb6c6965d38e4f692c767c8cc1bd67a9068d7`.

Whole-NCA hashes are not computed. References resolve through filename hints;
this is not signature authentication, executable validation or game execution.
Tests retain these observations, exercise explicit choices, and require native
launch preparation to validate the selected bytes again. The fixture must not
be hand-edited to simulate verified or unverified native results.
